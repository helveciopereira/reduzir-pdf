# ReduzirPDF

Aplicativo para **Windows 10/11 (64 bits)** que reduz o tamanho de PDFs em lote,
mantendo uma boa qualidade, inclusive de fotos.

## Baixar e instalar

**[⬇ ReduzirPDF-Setup.exe](https://github.com/helveciopereira/reduzir-pdf/releases/latest/download/ReduzirPDF-Setup.exe)**

- Instala para o seu usuário, **sem pedir administrador**.
- Cria atalhos no Menu Iniciar e na Área de Trabalho.
- Adiciona **Reduzir PDFs** ao botão direito do Explorer, em pastas e em PDFs. No
  Windows 11, o item fica em "Mostrar mais opções".

## Atualização automática

O app se atualiza sozinho e em silêncio. Quando há versão nova, ela é baixada em
segundo plano e instalada ao fechar o programa. Na próxima vez que você abrir, já
estará na versão nova.

## Desinstalar

Configurações → Aplicativos → ReduzirPDF → Desinstalar. O item do botão direito
também é removido.
